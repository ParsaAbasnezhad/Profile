Kahoot Answers Viewer

A lightweight companion overlay that fetches the correct answer set for a live Kahoot quiz and displays it in a clean, distraction-free panel — built originally as a fun scripting exercise.

#overview

This project came out of curiosity about how Kahoot's public quiz endpoints work. A small Express server polls the quiz session, parses the question set, and streams it to a minimal front-end overlay that renders in a fraction of a second — clean typography, no clutter, just the question and the highlighted answer.

#key-features

Instant answer lookup

Answers are resolved and displayed the moment a new question loads, with sub-second latency.

Minimal overlay UI

A distraction-free panel that stays out of the way until you actually need it.

Live leaderboard view

Tracks scores in real time alongside the answer panel for a fuller picture of the game.

Zero install

Runs entirely in the browser — no extension or executable required to try it out.
