#overview

Compromised bot tokens and rogue integrations can wipe a Discord server in seconds. ProtectX sits between the Discord API and the server, watching the rate and shape of destructive actions — channel deletes, role edits, mass bans — and automatically strips permissions from the offending account the moment a threshold is crossed. A companion React dashboard lets admins review the action log and fine-tune sensitivity per server.

#key-features

Real-time threat detection

Monitors the Discord audit log stream and flags destructive action bursts within milliseconds.

Automatic lockdown

Strips roles or kicks the offending account the instant a threshold is crossed — no admin needed.

Audit dashboard

A React panel shows every blocked action with context, so admins can confirm or override in one click.

Tunable sensitivity

Per-server thresholds mean a busy moderation team and a quiet hobby server both stay false-positive free.
